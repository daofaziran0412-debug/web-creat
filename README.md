# 网页快捷方式生成器

一个简单的Android应用，可以自定义图标和名称，一键创建网页桌面快捷方式。

## 功能
- 自定义快捷方式图标（从相册选择）
- 自定义桌面图标名称
- 输入网页URL
- 一键添加到手机桌面

## 使用方法
1. 选择图标图片
2. 填写桌面图标名称
3. 填写网页地址（如 https://www.baidu.com）
4. 点击「添加到桌面」
5. 在弹出的系统确认框中点击「添加」

## 注意事项
- Android 8.0以上系统会弹出确认框，需要手动点击添加
- 部分国产ROM（小米、OPPO、vivo）需要在系统设置中开启「创建桌面快捷方式」权限
- 图标建议使用512x512像素的正方形图片
